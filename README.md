Entry for make.fun's **"One-Star Review of Something Essential"** bounty ($5 in USDC).

The entry is a single-line one-star review in `entry.txt` — at most 160 characters, a deadpan complaint filed in earnest against an everyday essential that cannot be fixed.

## Run it

```sh
python3 main.py
```

`main.py` (stdlib only) copies the committed `entry.txt` into `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `out/`), which is what the harness reads.
